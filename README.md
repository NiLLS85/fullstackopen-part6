# Full Stack Open, parte 6

Ejercicios de la parte 6 del curso [Full Stack Open](https://fullstackopen.com/es/) de la Universidad de Helsinki: gestión del estado con Zustand, TanStack Query y Context.

Parte del repositorio de ejercicios del curso ([fs-statemanagement](https://github.com/fullstack-hy2020/fs-statemanagement)), con sus pruebas de Playwright, que se ejecutan en GitHub Actions en cada `push` a `main`.

| Carpeta | Ejercicios | Contenido |
|---|---|---|
| [unicafe](unicafe) | 6.1 | Contador de opiniones con un almacén de Zustand |
| [anecdotes](anecdotes) | 6.2 a 6.15 | Anécdotas con Zustand: votos, filtro, avisos temporales, servidor json-server y pruebas del almacén con Vitest |
| [query-anecdotes](query-anecdotes) | 6.16 a 6.22 | Anécdotas con TanStack Query y avisos con `useReducer` y Context |
| unicafe-tests, anecdotes-tests y query-anecdotes-tests | | Pruebas del curso (Playwright) |
